# Reverse Timeline Planner

Eine Streamlit-basierte Webanwendung für die schnelle Rückwärtsplanung von Projektzeiträumen mit visueller Gantt-Darstellung und PDF-Export.

## Funktionen

- **Reverse Timeline Planning**: Planung vom Projektende rückwärts
- **7 konfigurierbare Meilensteine** mit individuellen Dauern
- **Flexible Zeitberechnung**: Wahlweise Arbeitstage (Mo-Fr) oder Wochentage (Mo-So)
- **Interaktives Gantt-Diagramm** mit Plotly
- **PDF-Report Generator** mit Tabellen und Diagrammen
- **Kundenanpassung**: Firmenname, Ersteller und Anmerkungen
